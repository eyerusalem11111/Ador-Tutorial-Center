Official Multilingual Academic Operations Platform & Live Tutoring Job Board for Ador Tutorial Center (adortutorial.com).

== Description ==

This plugin integrates the complete Ador Tutorial Center operations platform into WordPress:
* Displays Our Mission, Vision, and 6 Core Values (Excellence, Integrity, Compassion, Innovation, Partnership, Empowerment).
* Displays the 3-column Live Tutoring Job Board broadcasting stream across Addis Ababa neighborhoods.
* Supports 5 languages (English, Amharic, Oromo, Tigrinya, Somali).
* Connects with Ultimate Member tutor and parent registration forms, auto-detecting user roles upon login.
* Provides parent tuition fee payment receipts ledger, tutor membership management, and student evaluation tracking.

== Installation ==

1. In WordPress Admin, go to Plugins > Add New > Upload Plugin.
2. Select ador-tutorial-portal.zip and click Install Now.
3. Click Activate Plugin.
4. Add the shortcode [ador_portal] to any Elementor page, Gutenberg block, or WordPress template.
